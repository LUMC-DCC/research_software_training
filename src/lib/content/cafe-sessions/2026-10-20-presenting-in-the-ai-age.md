## Session Summary

Making things with an AI assistant, with slides as the test case. Slides are plain text, code and data, and you see the result in seconds, which makes them a good place to practise the loop: describe what you want, let the assistant change the files, look at the result, check the diff and the numbers, and commit or undo.

## Topics Covered

- One application of AI: the describe → generate → see → check → keep loop
- Slidev in VS Code with Claude: from a markdown file to a deck, then structure and layout tweaks
- A `CLAUDE.md` briefing: house style, gotchas and red lines, written once
- Charts from data: a component built from a CSV, revealed step by step on clicks
- Quarto in RStudio with Claude: replacing typed numbers with values computed in R
- Git as the safety net: commits, branches, and going back when the assistant gets it wrong
- Red lines: numbers come from code, no patient data in prompts, check generated images, accessibility
