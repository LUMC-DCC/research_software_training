## About this session

Join us at the Coding Café, the monthly meetup for everyone at LUMC who writes code for research: a short talk, then time to discuss questions and solve problems together.

This time: documenting your research code, so that a colleague (or you, a year from now) can understand and run it.

## In this session you will

- Write a README: what the code does, how to install and run it, and what input and output to expect
- Learn the layers of documentation: README, docstrings and comments, and what belongs where
- Use an AI assistant to draft documentation, and check what it gets wrong
